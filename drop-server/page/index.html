    Route van een bestand

    1. 1 Bestand
    2. 2 Versleutelen Publieke sleutel ontvanger + tijdelijk sleutelpaar
    3. 3 Sealed box 1010 1101 0101 0110 1010 1100 …
    4. 4 Verzenden via server Server ziet alleen versleutelde data
    5. 5 Ontsleutelen op versleutelde schijf Met de privésleutel van de ontvanger, op de versleutelde schijf
    6. 6 Bestand op versleutelde schijf Bestand ontsleuteld op versleutelde schijf

    Hoe wordt de publieke sleutel van de ontvanger gebruikt?

    De publieke sleutel van de ontvanger wordt gebruikt tijdens het versleutelen. Daarmee wordt van het bestand een sealed box gemaakt.

    De publieke sleutel vergrendelt dus het bestand, maar kan het niet openen. Alleen de bijbehorende privésleutel van de ontvanger kan het bestand weer ontsleutelen.

    Tijdelijk sleutelpaar

    Voor elk bestand wordt een tijdelijk sleutelpaar gebruikt.

    De geheime tijdelijke sleutel wordt direct na het versleutelen gewist.
